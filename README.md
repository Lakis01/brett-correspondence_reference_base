# Brett Correspondence Reference Base

High-level correspondence chess reference database compiled and filtered for use with [Brett](https://github.com/Lakis01/Brett).

- **Source:** International Correspondence Chess Federation (ICCF)
- **Games:** 87,927
- **Ratings:** Both White and Black rated ≥ 2350 Elo (range 2350–2724)
- **Coverage:** 2021-01-01 through 2026-09-25
- **Branch Truncation:** Mainlines and variations capped at 70 plies for optimal opening and middle game preparation
- **License:** Non-commercial / no resale. See [LICENSE-CRB.txt](LICENSE-CRB.txt).

## Release Asset

The release asset `Correspondence_2350.tar.gz` bundles:
- `Correspondence_2350.si4` (SCID index)
- `Correspondence_2350.sg4` (SCID moves)
- `Correspondence_2350.sn4` (SCID player names)
- `Correspondence_2350.brettpos` (precompiled Brett opening-tree index)
- `LICENSE-CRB.txt` (License agreement)
